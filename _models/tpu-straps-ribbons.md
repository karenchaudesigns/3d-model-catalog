I wanted to use this concept to make ribbons for my use cases – how will you customize them to use in your projects?

**NOTE: **For the thin ribbons I shared (thickness of only one line width), I'm getting a little print defect on one end (the inside end) – there's a bit of extra filament that can be trimmed off.

For these ribbons with ***only one line width of thickness***, I recommend printing it in vase mode.

### Recommended Print Settings

I printed with:

- 0.4mm nozzle
- 0.42mm line width
- HS TPU95A
