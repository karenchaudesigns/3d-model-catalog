I'm excited to bring you my design of the classic ring toss game with an Easter egg theme!
The modular pieces make this set fun to mix and match and set up in many different ways for better replayability!

This set includes:
- Egg-shaped base
- Rods (3 heights)
- Egg-shaped rings (variety of decorative and difficulty levels)
- Point labels: 1, 2, 5, 10, 20, 50 (if you want different points for each target)

### Recommended Print Settings

- Recommended to print on a textured build plate for a fun look!
- 0.2mm layer height
- 0.4mm nozzle
