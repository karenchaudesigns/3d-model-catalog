For Bambu Studio users:Open the 3mf project file to find an example of a custom IO shield that you can edit in Bambu Studio to customize to your motherboard's needs.

For other slicers:Use the STL file that has the blank along with the other parts as an assembly, so you can download the IO Shield Builder STL, select the model, split to parts and then rearrange/edit the placements of all the cutout parts as needed and make sure to select the cutout parts and change the type to Negative Part. Slice, print and enjoy!

The design is an assembly consisting of the blank IO shield and objects (shaped for various ports) set as negative parts so they become cutouts for the ports.

#### You can customize the IO shield to fit your motherboard in several ways, including:

- adjusting (e.g. scaling, moving) the negative parts within the assembly for a better fit
- deleting or duplicating the existing negative parts for fewer or more ports
- adding primitives (or other models) to the assembly, changing the type to “Negative Part” to create holes for additional ports

*The example IO shield in the 3mf file is designed for the ****Jetway NF96FL-525 LF**** motherboard that I received as a request on MakerWorld.*

### Design & Share

Design your own IO shield for your specific motherboard and upload  as a remix so others don't have to duplicate the effort!
