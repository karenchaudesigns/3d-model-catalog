I made these MakerChips with a duck cutout that fit 15mm tall [Baby Ducks](https://www.karenchaudesigns.com/3d/baby-ducks-free-to-a-good-home)

**STLs available:**

- Single color blank chip
- 2-color blank chip
- Multi-color chip with "karenchaudesigns.com/ducks" text

3mf project file also included for blank variations

### Recommended Print Settings

- 0.4mm nozzle
- 0.2mm layer height
- 15% honeycomb infill
- Only one wall on first layer
- Scarf seam
- Initial layer speed: 15mm/s
