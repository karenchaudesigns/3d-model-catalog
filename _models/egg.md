This is a model of an egg with a flat bottom so that it can be displayed upright on a flat surface easily.

Print it with TPU for a squishy egg -- just like a peeled hard-boiled egg!

Print the one with the hole to use with "The Squeaker!" to make this into a squeaky toy.

- The 3MF file is configured to be compatible with "The Squeaker!" – Make sure to print this egg in TPU95A (or softer)!
- The STL file is included for your regular non-squeaky printing purposes.
